# 28 — 周工时表录入与提交

**What to build:** 员工在一张以周一至周日为列的网格里填工时，粒度是"某人某天在某任务上花了多少分钟"。填完提交给经理审批。

**结构约束:** 界面遵循 `docs/architecture/frontend-design-system.md` §6.1（键盘 Tab/Enter 导航、实时合计、超额警告不截断）；数字使用等宽数字；375px 宽度下明确降级为"请用桌面端"提示而非硬挤。

**Blocked by:** 27 — 项目与任务（含可计费标记）

**Status:** done

- [ ] 一周从周一开始，共七天；员工可为任意一天填任意多个"项目 + 任务 + 分钟数"条目
- [ ] 每人每周只有一张工时表，按周起始日唯一确定
- [ ] 网格界面支持快速录入、复制上一周、按任务筛选，并实时显示每日合计与本周合计
- [ ] 每日合计超过该日作息时长时给出提示但允许提交（不静默截断，也不硬拦）
- [ ] 分钟数必须为正整数，单条上限合理（如不超过 24 小时），非法输入被拒绝
- [ ] 提交后可查看状态（草稿 / 审批中 / 已通过 / 已驳回）；草稿可自由编辑，已提交不可直接编辑
- [ ] 被驳回后可修改并重新提交，历史提交记录保留
- [ ] 只能为本人填报工时，代填返回 403
- [ ] 员工不能在项目起止日期之外填报该项目的工时

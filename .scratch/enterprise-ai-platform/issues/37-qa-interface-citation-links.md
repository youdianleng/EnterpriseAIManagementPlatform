# 37 — 问答界面与引用回链

**What to build:** 员工有一个像样的问答界面：左侧会话列表、右侧对话流、底部输入框。答案流式出现，引用可以点击并**跳转到原文的对应页**。历史会话能翻，也能自己删掉。

**Blocked by:** 36 — 个人文档与可见性

**Status:** ready-for-agent

- [ ] 会话列表展示历史会话，可新建、重命名、删除；删除后本人不可再看到
- [ ] 对话流支持流式渲染、Markdown 排版、代码与表格的正确显示
- [ ] 引用以可点击的角标呈现，点击后在侧栏展示原文片段，并提供"打开原文"跳转到对应页码
- [ ] 拒答的回答有明确的视觉区分，不与正常回答混淆
- [ ] 界面明确显示回答所依据的范围（公司知识库 / 含个人文档）
- [ ] 会话与消息保留 90 天后自动清除，界面上明确告知该期限
- [ ] 用户可自行删除自己的会话；删除是即时的
- [ ] 会话与消息**没有**对普通人力资源角色开放的入口；只有合规角色在留痕的前提下可查（该入口在后续工单实现）
- [ ] 界面西/英双语，流式过程中切换语言不影响正在生成的回答

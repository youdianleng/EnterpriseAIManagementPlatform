# 45 — 员工工资单自助下载与可见份数

**What to build:** 员工在个人中心能看到自己最近的工资单并下载。可见份数默认是最近 3 份，由系统参数控制。每一次下载都留痕。

**Blocked by:** 44 — 财务批量上传工资单与缺失清单

**Status:** ready-for-agent

- [ ] 员工在个人中心看到自己已发布的工资单列表，按月份倒序排列
- [ ] 可见份数由系统参数控制，默认为最近 3 份；调整参数不需要改代码
- [ ] 超出可见份数的更早工资单**不出现在响应中**，界面上也不提示"还有更多但你看不到"
- [ ] 下载以受权限保护的接口提供，直接猜测文件路径无法访问
- [ ] 每次下载写入审计日志（谁、哪个月份、何时）
- [ ] 员工只能下载自己的工资单，访问他人返回 403
- [ ] 财务与人力资源可查看上传与下载情况的统计，但**不需要**能打开工资单内容之外的额外信息
- [ ] 员工界面明确说明工资单由财务部上传，如有疑问的联系方式

# 47 — 培训记录、数据导出与留存说明

**What to build:** 三件收尾的事：人力资源能维护培训课程与员工的完成记录；员工能一键导出"系统里关于我的全部数据"；系统里有一页明确告诉每个人各类数据会保存多久、以及为什么有些数据不能删除。

**Blocked by:** 18 — 离职生效与账号禁用

**Status:** ready-for-agent

- [ ] 培训课程含编码、双语名称、简介、是否必修、时长、证书有效期
- [ ] 员工可被登记报名，状态覆盖已报名 / 进行中 / 已完成 / 未通过 / 已过期，含完成日期与成绩
- [ ] 证书类记录带到期日，临近到期时在员工个人中心提示
- [ ] 员工可一键发起"导出我的数据"，后台异步生成包含结构化数据（JSON）与可读摘要（PDF）的压缩包
- [ ] 导出内容覆盖：个人档案、职位与部门历史、考勤记录、请假与年假、工时、审批记录、培训记录、通知；**含系统日志中与本人相关的审计条目**
- [ ] 导出文件通过有效期有限的受保护链接下载（默认 7 天），过期后需重新发起
- [ ] 导出请求与下载均写审计日志；导出只能由本人发起，管理员与人力资源不能代替员工导出（合规要求由本人行使）
- [ ] 留存说明页面逐类列出数据的保存期限与依据，并明确说明工时与薪酬类数据因法定义务不能应要求删除
- [ ] 留存策略以数据结构表达（类别、月数、依据、备注），页面从数据渲染而非写死文字
- [ ] 仓库中有一份与实现一致的处理活动记录与数据字典文档

## PDF 依赖可用性（预验证）

"可读摘要（PDF）"需要写 PDF；`pypdf` 只读不写版式，不能胜任。镜像基础是
`python:3.13-slim`（没有 cairo/pango 等系统库），所以选择面是**纯 Python wheel**，
以下两个已用 `pip download --no-deps` 实测可取得：

| 包 | 实测版本 | 说明 |
|---|---|---|
| `fpdf2` | 2.8.8 | 纯 Python、体积小，表格与分页够用 |
| `reportlab` | 5.0.1 | 更完整，同样不需要系统库 |

两个都可行，选一个并在工单实现说明里写清理由即可；**不要**选需要 apt 系统库的方案
（WeasyPrint 一类），那会把镜像构建变成另一件事。装配方式与工单 38 相同：
写进 `api/pyproject.toml` + 更新 `api/uv.lock` + `docker compose build api`，
且重建期间不要有并发测试在跑。

压缩包本身用标准库 `zipfile` 即可，不引入新依赖；"有效期有限的受保护链接"复用既有文档
下载的签名/票据机制，不要另造一套。

# 36 — 个人文档与可见性

**What to build:** 员工可以上传自己的文档（合同、证明、个人笔记），默认**只有自己能看到**。他可以选择公开给本部门。但公开不等于绕过密级——个人文档公开后仍受公司密级规则约束。个人文档**不会**进入公司知识库的检索池，只在所有者本人提问时才可能被召回。

**Blocked by:** 35 — 密级 × 部门检索过滤与越权测试

**Status:** ready-for-agent

- [ ] 上传时可选择可见性：仅自己 / 本部门；默认仅自己
- [ ] 个人文档标记为非公司知识库内容，与公司文档在数据上可区分
- [ ] 个人文档的所有者始终是自己，不能被转交给他人
- [ ] 公司知识库检索时**不召回**任何他人上传的个人文档；只有提问者本人的个人文档可被召回
- [ ] 公开给本部门的个人文档，对同事仍须满足密级条件才可见
- [ ] 员工可撤销公开，撤销后同事立即无法访问，缓存同步失效
- [ ] 他人访问未公开的个人文档返回 403 且资源在列表中完全不存在
- [ ] 回答中若引用了个人文档，必须在回答顶部明确标注"以下内容来自个人文档（非公司知识库）"
- [ ] 有测试覆盖上述全部可见性组合

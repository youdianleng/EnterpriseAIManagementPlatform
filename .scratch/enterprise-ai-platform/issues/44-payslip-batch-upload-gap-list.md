# 44 — 财务批量上传工资单与缺失清单

**What to build:** 财务选定月份，一次性上传该月全部工资单 PDF。系统给出两份清单：**已上传**的与**缺失**的（哪些员工这个月还没有工资单）。这样漏发能被当场发现，而不是等员工来问。

**Blocked by:** 43 — 薪酬档案

**Status:** ready-for-agent

- [ ] 财务可按月份一次上传多个 PDF，系统通过文件名中的员工编号或界面选择完成归属匹配
- [ ] 无法匹配到员工的文件被单独列出并说明原因，不静默丢弃
- [ ] 上传完成后展示两张清单：成功归属的、以及该月**应有但缺失**的员工（依据在职状态与薪酬档案判定）
- [ ] 同一员工同一月份重复上传被视为替换，界面明确提示将覆盖，并要求确认
- [ ] 每个工资单记录文件大小与内容校验和，用于事后核对是否被替换
- [ ] 工资单状态为"已发布"或"已撤回"，只有已发布的对员工可见
- [ ] 上传完成自动通知相关员工并写入审计（记录上传人、月份、份数）
- [ ] 只有财务角色能上传；人力资源与管理员上传返回 403
- [ ] 缺失清单可导出，便于财务跟进

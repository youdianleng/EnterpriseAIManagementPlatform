# 22 — 工作日程、节假日表与月度应出勤

**What to build:** 人力资源维护每个部门的作息（含周五短班的 intensivo 制）以及年度节假日表；员工可以有个人作息覆盖（兼职、特殊岗位）。系统据此算出每个人每个月的应出勤工时。这个数字会**快照存档**，因为四年后需要能证明当时是按什么算的。

**Blocked by:** 21 — 打卡事件流与当日记录

**Status:** done

- [ ] 作息配置可挂在部门上作为该部门默认，并可对个别员工做带生效期的覆盖
- [ ] 支持"周一至周四 8 小时、周五 6 小时"这类逐日不同的周作息，含休息时长与上下班时间
- [ ] 支持兼职的缩短工时设置
- [ ] 节假日表是可导入的数据（含国家 / 自治区 / 地方三级范围与年份），**不在代码中硬编码**
- [ ] 人力资源可在界面上增删改节假日，修改后缓存立即失效
- [ ] 月度应出勤 = 该月工作日 × 当日作息时长 − 节假日，按员工逐个计算
- [ ] 计算出的月度应出勤连同**当时使用的作息与节假日版本**一起快照存档；事后修改作息不会改变历史快照
- [ ] 有测试验证：某月应出勤与实际日历一致，且历史快照在作息被改动后仍是原值

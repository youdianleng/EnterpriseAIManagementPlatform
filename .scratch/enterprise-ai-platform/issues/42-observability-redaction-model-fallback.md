# 42 — 可观测性脱敏与模型降级

**What to build:** 助手的运行情况可以在追踪平台上看到，便于排查问题——但**员工对话内容、提示词、检索到的文档片段一律不出境内**，只发送工具名、节点流转、耗时、token 数与错误类型。同时，主模型不可用时自动切到备用供应商，并把实际使用的供应商记下来。

**Blocked by:** 41 — 人审确认点与 agent_actions 审计

**Status:** ready-for-agent

- [ ] 存在唯一的追踪上报出口，且带有一个**白名单**过滤器，只有被允许的字段能外发
- [ ] 被禁止外发的字段明确列出：对话正文、消息列表、提示词、模型补全、查询语句、文档片段、引用内容、工具入参、工具出参
- [ ] 过滤器有单元测试，断言序列化结果中**不出现**任何禁止字段与它们的值（包括嵌套结构）
- [ ] 模型供应商抽象为统一接口，配置中定义调用顺序（OpenAI 主，DeepSeek / Claude 备）
- [ ] 降级**只在技术失败时发生**（超时、限流、服务端错误、连接失败）；不因"回答质量下降"而自动切换
- [ ] 每次请求记录实际使用的供应商与模型，可在会话记录中查到
- [ ] 降级事件写入结构化日志与审计（不含对话正文）
- [ ] 嵌入模型**不参与**自动降级（维度不同不可混用）；若嵌入服务不可用，明确报错并停止入库，不写入维度不符的向量
- [ ] 有测试：模拟主供应商故障，验证自动切换且记录正确；模拟全部供应商故障，验证给出明确错误而非静默空回答

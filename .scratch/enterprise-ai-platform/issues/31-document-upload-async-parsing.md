# 31 — 文档上传与异步解析管道

**What to build:** 人力资源或任何被授权的用户上传 PDF / Word / Excel / 纯文本 / Markdown 文档，指定部门与密级。系统在后台解析文本，前端看到进度条从"处理中"推进到"就绪"。原始文件被完整保留，供日后引用回链。扫描件会被明确拒绝并提示需要文字版。

**Blocked by:** 15 — 权限矩阵与越权测试套件

**Status:** ready-for-agent

- [ ] 支持上传 PDF、DOCX、XLSX、TXT、Markdown；其他类型被拒绝并给出可读的西/英提示
- [ ] 单文件大小上限为 50MB，超限被拒绝；文件名规范化以防止路径穿越
- [ ] 上传立即返回并落盘原始文件，解析在后台执行；HTTP 请求不等待解析完成
- [ ] 前端显示每个文档的处理状态与进度，失败时显示原因
- [ ] 文档记录含标题、所属部门、密级、所有者（公司文档为空）、分类、标签、语言、状态
- [ ] 未提取到任何文本时（典型为扫描件）状态置为失败并提示"未提取到文本，请上传文字版"，**不做 OCR**
- [ ] 原始文件保留且可通过受权限保护的接口下载
- [ ] 同一文件重复上传通过内容校验和被识别并提示，不静默产生重复文档
- [ ] 上传、解析成功、解析失败三类事件写入审计日志
- [ ] 解析任务的失败可重试，且重试不产生重复的分块数据

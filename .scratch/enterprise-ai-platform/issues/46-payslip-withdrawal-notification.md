# 46 — 工资单撤回与已下载者通知

**What to build:** 财务发现传错了工资单，可以撤回。撤回后该份工资单立即从员工列表消失，但员工看到的不是"凭空少了一份"，而是一条"该月工资单已撤回，请联系财务"的占位说明。已经下载过的人会收到一条通知。

**Blocked by:** 45 — 员工工资单自助下载与可见份数

**Status:** ready-for-agent

- [ ] 财务可撤回某员工某月份的工资单，需填写撤回原因
- [ ] 撤回后该份工资单从员工的可见列表中立即消失，文件接口也同时不可访问
- [ ] 员工侧出现占位提示"该月工资单已撤回，请联系财务"，避免员工误以为系统丢数据
- [ ] 对该月份**曾经下载过**的员工发送通知，说明工资单已被撤回及原因
- [ ] 未下载过的员工不收到撤回通知（避免制造无谓疑问）
- [ ] 撤回与原因写入审计日志，记录操作人、时间、月份、受影响员工数
- [ ] 撤回的记录保留在库中（软撤回），可被财务与合规查询到，不物理删除
- [ ] 撤回后可重新上传同月份的工资单，重新上传后员工侧恢复正常显示
- [ ] 只有财务角色能撤回；其他角色返回 403

# 18 — 离职生效与账号禁用

**What to build:** 离职单在生效日当天自动完成收尾：账号被禁用、登录会话被立即清掉、员工状态改为已离职，但**历史记录一律保留不动**（工时与薪酬有法定留存期，不能因为人走了就删）。

**Blocked by:** 17 — 人员变动单：入转调离

**Status:** ready-for-agent

- [ ] 生效日当天：账号被禁用、员工状态变更为已离职、该账号在 Redis 中的全部会话被删除
- [ ] 被禁用的账号即使凭证正确也无法登录，提示为可读的西/英文案（不暴露"该用户存在"之外的信息）
- [ ] 该员工的考勤、工时、请假、薪酬、工资单、审批历史**全部保留且可查**
- [ ] 离职员工不再出现在通讯录、部门人数统计、可选审批人列表中
- [ ] 离职员工不能被重新创建账号；如需返聘，必须通过新的入职变动单恢复（行为需明确并测试）
- [ ] 若离职员工是某人的审批上级，系统提示人力资源需要为受影响的下属重新指派上级，并在重新指派前阻止相关单据提交（或自动回退到上级的上级，二者择一并在文档中写明）
- [ ] 上述所有动作写入审计日志

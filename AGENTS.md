# Agent skills

### Issue tracker

Tickets live as local markdown files under `.scratch/<feature-slug>/issues/`, one file per ticket, numbered from `01` in dependency order. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: the implementation baseline is `docs/DESIGN.md`; code organization is fixed by `docs/architecture/codebase-design.md`; UI is fixed by `docs/architecture/frontend-design-system.md`. `CONTEXT.md` and `docs/adr/` sit at the repo root as they are created. See `docs/agents/domain.md`.
